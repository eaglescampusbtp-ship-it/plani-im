# Plani Im

Aplikacion personal (PWA) për projektet, detyrat, dokumentet dhe paratë.

- Hapet në shfletues dhe instalohet në telefon (« Instalo aplikacionin »).
- Të dhënat nuk ruhen këtu: ato janë në një bazë të dhënash private, të mbrojtur me hyrje.

Librari të përfshira: [supabase-js](https://github.com/supabase/supabase-js) (MIT) dhe [PDF.js](https://github.com/mozilla/pdf.js) (Apache-2.0).
